Fire Extinguisher

School Conjuration; Level Arcane 2, Divine 2
casting
Casting Time Attack Action
Components V, S
effect
Range close (25 ft. + 5 ft/2 levels)
Effect cloud of dust, spreads in a 20 foot radius Duration1 minute/level
Saving Throw Fortitude negates; Spell Resistance none
description

Dust Cloud summons a cloud of dust. It functions as the spell Obscuring Mist except instead of mist it is a cloud of dust which causes creatures inside the cloud must make a fortitude save or be blinded for 1d4 rounds. The cloud has a second function. Any open flame within the cloud causes it to explode, dealing 1d4 points of fire damage per two caster levels (maximum 5d4).
